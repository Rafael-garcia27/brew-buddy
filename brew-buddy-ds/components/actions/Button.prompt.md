Schaltfläche in vier Varianten; primary ist die eine Hauptaktion eines Bildschirms.

```jsx
<Button size="lg" block>V60 brühen</Button>
<Button size="sm" variant="ghost">Später</Button>
```

Disabled = 40 % Deckkraft. In Organic ist `--radius-btn` eine Pille und primary trägt `--shadow-soft`. Symbol + Text mit gap 8 px.
