Die drei Zahlen des Rezepts (In · Time · Out) nebeneinander und groß.

```jsx
<Triad items={[
  { label: 'In', value: '18,0', unit: 'g', onEdit },
  { label: 'Time', value: '27–30', unit: 's' },
  { label: 'Out', value: '36,0', unit: 'g', onEdit },
]} />
```

Größe folgt der Länge: < 5 Zeichen 28 px, ≥ 5 20 px, ≥ 9 17 px. Einstellbar = gestrichelte Akzentlinie.
